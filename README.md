# Aurum

Личный учёт финансов. Новое приложение, написанное с нуля.

- Svelte 5 + Vite, PWA для iPhone (добавить на экран «Домой»)
- Дизайн: iOS, чёрный + золото, светлая и тёмная тема по настройке телефона
- Нижнее меню: Главная, Счета, Операции, Бюджет, Ещё (Liquid Glass)

## Запуск

```
npm install
npm run dev
```

Публикация: GitHub Pages через GitHub Actions (`.github/workflows/deploy.yml`) при слиянии в `main`.
